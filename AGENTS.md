# Agent Autonomy Rules

- **Auto Execution Mode**: Always execute necessary commands, tools, and file edits autonomously without asking for intermediate confirmation.
- **Workflow**: 
  1. Only discuss and confirm the plan with the user BEFORE beginning execution.
  2. Once approved or when instructed to proceed, execute all steps through to completion without pausing or asking questions.
  3. Report final outcomes and summary AFTER all work is completed.
